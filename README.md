# 🍓 Morangos Tech

Projeto de **Análise de Dados com Python e Pandas**, focado na identificação de **Gargalos de Atendimento** a partir de dados reais de suporte técnico.

Direto ao ponto: pegar dados, analisar, gerar gráfico e extrair decisão.

---

## 📌 Sobre o projeto

O **Morangos Tech** é um projeto de análise operacional que investiga gargalos no atendimento de suporte técnico, usando dados históricos para identificar onde o fluxo trava, por quê trava e o que pode ser feito para melhorar.

O projeto analisa chamados de suporte ao longo de **4 meses**, avaliando:

* Volume de atendimentos
* Taxa de resolução
* Tempo médio por operador
* Gargalos por categoria, setor e turno

O resultado final é um **relatório analítico com gráficos**, voltado para apoio à tomada de decisão.

---

## 🎯 Objetivo

* Identificar gargalos no atendimento
* Apoiar decisões estratégicas com dados
* Melhorar eficiência operacional
* Reduzir tempo médio de atendimento

---

---

## 📊 Principais indicadores analisados

* Total de chamados: **3000**
* Chamados finalizados: **941**
* Taxa de resolução: **31,37%**
* Chamados em aberto: **1070**

---

## 🚨 Gargalos identificados

* **Categoria:** Suporte Técnico (maior tempo médio)
* **Setor:** TI (concentração de chamados complexos)
* **Turno:** Tarde (desequilíbrio entre demanda e capacidade)

Esses dados indicam falhas de triagem, sobrecarga operacional e necessidade de redistribuição de recursos.

O projeto gera um **relatório em PDF** com:

* Gráficos de desempenho por operador
* Análise de tempo médio de atendimento
* Identificação de gargalos operacionais
* Considerações finais baseadas em dados
